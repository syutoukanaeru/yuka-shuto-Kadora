## 3. コンポーネント構造表

| コンポーネント名  | 階層      | 役割・責務                               | 再利用性                |
| :---------------- | :-------- | :--------------------------------------- | :---------------------- |
| `Header`          | Global    | 全体共通ナビゲーション                   | ✅ 高（全ページ共通）   |
| `ProfileCard`     | Domain    | ユーザー基本情報とプロフィール画像の表示 | ❌ 中（マイページ専用） |
| `AchievementGrid` | Layout    | 実績配置するコンテナ                     | ❌ 低（レイアウト用途） |
| `AchievementCard` | Component | 各実績のタイトル、レベル、アイコン表示   | ✅ 高（実績一覧等）     |
| `Footer`          | Global    | 著作権およびフッターリンク               | ✅ 高（全ページ共通）   |

## 4. レイアウト仕様

| エリア           | 採用レイアウト手法 | CSSプロパティ仕様                                                                                   |
| :--------------- | :----------------- | :-------------------------------------------------------------------------------------------------- |
| ヘッダー         | Flexbox            | `display: flex; justify-content: space-between; align-items: center;`                               |
| プロフィール領域 | Flexbox            | `display: flex; gap: var(--space-lg); align-items: center;`                                         |
| 実績一覧         | CSS Grid           | `display: grid; grid-template-columns: repeat(auto-fit, minmax(240px, 1fr)); gap: var(--space-md);` |
